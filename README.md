# 🚗 Car Price EDA and Prediction

This project focuses on **Exploratory Data Analysis (EDA)** and **Machine Learning modeling** to understand the factors affecting car prices and to build a model for price prediction.

---

## 📌 Project Overview

Car prices depend on many features such as engine size, horsepower, fuel type, and more.
In this project, we:

* Explored the dataset
* Cleaned and prepared the data
* Analyzed relationships between features
* Built machine learning models to predict car prices

---

## 📊 Dataset

The dataset contains various car attributes such as:

* Car brand
* Fuel type
* Engine size
* Horsepower
* Weight
* Mileage
* Price (target variable)

---

## 🔍 Exploratory Data Analysis (EDA)

Key steps in EDA:

* Handling missing values
* Detecting and treating outliers
* Correlation analysis
* Feature distribution visualization
* Relationship between important variables and price

---

## ⚙️ Machine Learning Pipeline

Steps used in modeling:

1. Data preprocessing

   * Encoding categorical features
   * Feature scaling
2. Train-test split
3. Model training
4. Model evaluation

---

## 🤖 Models Used

* Linear Regression
* Decision Tree Regressor
* (Optional) Random Forest Regressor

---

## 📈 Evaluation Metrics

Models were evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
